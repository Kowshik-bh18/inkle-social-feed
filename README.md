# 🐦 Django Social Feed

A full-featured social activity feed web application built using **HTML, CSS, JavaScript, Django, and Bootstrap 5**.  
Users can create profiles, share posts, follow others, and engage through a clean, minimal social dashboard.  
The project focuses on simplicity, clean architecture, and scalability.

# 📘 About the App

This application replicates the core features of a lightweight social media platform.  
The UI is built using **HTML + CSS + Bootstrap**, with interactivity provided by **JavaScript**, and the entire backend is powered by **Django**.

The goal was to build a clean and functional system where users can interact, post, follow each other, and manage their profiles easily.

---

## ✨ Features Included (Detailed)

### 👤 **User Profiles**
- Users can create a new profile with account registration  
- Secure login system using Django authentication  
- Users can update profile information including:
  - Name  
  - Bio  
  - Avatar/Profile picture  
- Users can deactivate (delete) their account at any time  

---

### 👥 **User Interactions**
- View list of all users  
- See whether you already follow a user or not  
- Visit any user’s public profile  
- Follow and unfollow users with a single click  
- Earn coins for certain interactions (e.g., posting)

---

### 📝 **Posts & Activity Feed**
- Create new posts with text + image  
- Live preview of uploaded images before posting  
- Posts appear on a global dashboard in **chronological order**  
- Users can delete their own posts  
- Timeline is clean and simple, designed using Bootstrap cards

---

### 🪙 **Coins System**
Users receive coins for specific actions (like creating posts).  
These coins may later be used for:
- User rewards  
- Unlocking profile features  
- Gamification elements (future updates)

---

## 🎨 User Interface & Frontend

The frontend is built using:
- **HTML5** for layout  
- **CSS3** for styling  
- **Bootstrap 5** to ensure a responsive UI  
- **JavaScript** for dynamic behaviors (like previews, follow buttons, etc.)

The UI is clean, minimal, and mobile-responsive.

---
